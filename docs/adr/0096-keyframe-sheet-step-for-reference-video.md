# 参考生视频的起始帧联合图（keyframe sheet）：按站位与起始景别出图，作为首帧参考随请求发出

参考生视频以角色、场景、道具的资产图驱动，每个视频单元独立生成。单元之间的空间关系（谁坐在哪一侧、朝向、服装）只存在于文字里，视频模型每次都重新决定一次，相邻单元因此出现座位互换、服装变化、背景不一致。靠改写提示词压不住这类漂移。我们在导演审阅与提示词编写之间新增可选步骤：为每个单元出一张「起始帧」图，随该单元的参考图一起发给 H3。

## Evidence

2026-10 在真实项目上做了小样验证（`docs/research/` 之外，结论记在此处）：

- 把「当前单元起始景别」的一格图作为 `<Picture N>`，prompt 写「the shot begins from `<Picture N>`」：座位、服装、光线与上一单元一致，镜头仍按导演说明推进并切到第二镜。
- 把一格「宽景」图作为只借布局的弱参考（`weak_reference`，写明「角度与景别不跟图」）给一个以特写开场的单元：模型照抄了宽景的景别，第二镜没有切到另一人。**图的景别会被当作首帧锁死，不存在「只借布局」的用法。**
- 场景资产图是室外时，室内单元的空间由模型自行编造；补一张室内场景资产图后同类漂移消失。
- 人物三视图里脸只占百分之几的画面，联合图上人物脸型、肤色会漂；加入从人物图裁出的脸部特写作为额外参考并在 prompt 里写明脸部特征后明显收敛。联合图的参考图里不放任何视频帧，视频帧会把那一单元的偏差带进来。

## Decisions

- **只有一种用法：首帧（`begin`）**。一个单元只用起始景别与自己第一镜一致的格子；没有这样的格子时该单元不带起始帧，按现有路径生成。不设「布局参考」。
- **格子按（站位，起始景别）去重，不按单元数**。同一站位下起始景别相同的单元共用一格；站位变化（起身、换位）新增一组格子。联合图固定 2×2，每张最多 4 格，同一场景（地点）的格子装进同一张，超出则接下一张；不足 4 格的位置留灰色占位，切分时丢弃。联合图比例取项目比例。
- **格子的规划由一次文本调用产出，机械校验后落盘**（`plan_keyframes`）：输入是该集每个单元的正文与导演说明、已登记的角色与场景；输出是格子清单（标签、场景、站位、起始景别、出镜角色、使用它的单元）。校验：每个单元至多属于一格，单元与角色、场景名必须已登记，出镜角色必须出现在单元正文的 `@` 引用里。规划不改导演数据，也不改脚本。
- **数据不进 `project.json` 与正式脚本，不引入 schema 迁移**。看板放 `drafts/episode_N/keyframes.json`，图放 `keyframes/episode_N/`。单元与格子的映射只存在看板里；单元正文与 `h3_prompt` 载荷保持原样、不因看板变化而过期。
- **参考图在请求期派生，提示词在渲染期机械补写**。投影在资产参考图之后追加该单元的已审核格子作为 `<Picture N>`；`render_h3_prompt` 在 `subject_definitions` 与 `[Shot 1]` 前缀处补写「the shot begins from `<Picture N>`」一句，不依赖提示词编写的模型自觉。已发出的参考图总数仍受模型上限约束，超限时丢弃起始帧并给出提示，不挤掉角色图。
- **审阅**：联合图可整体或按格重生；人工逐格标记「已审核」，并在审阅界面把格内人脸与角色脸部特写参考并排比对。未审核的格子不进请求。看板记录每格生成时依据的指纹（站位、景别、出镜角色、场景与角色参考图摘要），依据变化即标为过期。
- **联合图的参考图**：场景用该格场景的资产图；每个出镜角色给「全身三视图」，本体角色若在角色卡上登记并生成了「Face」衍生（脸部特写）则额外给一张脸图。没有脸图的角色、以及 `本体/衍生` 形态（如年轻形态，长相随脸图而来但年龄不同）只用全身图，不自动裁脸。prompt 用英文，参考图按「Image N」编号，每格写明各人物对应的图号；人物外观不复述角色描述，只以参考图为准。
- **非强制**：未生成或未审核起始帧时视频仍可生成，只给提示；不改变存量项目的任何行为。参考生视频以外的路线不适用。
- **成本**：联合图按图片计费（当前约每张 0.015 美元），一集预计 3–5 张，约占该集视频费用的 1–2%，进入既有的准入与计费流程。

## Consequences

- 起始帧与场景资产图缺失是两个独立问题：补全场景资产（尤其室内场景）本身就能消除一部分漂移，起始帧只处理站位与景别。
- 起始帧会把图里的偏差带入视频（例如人脸不像）。因此必须在审阅时核对人脸，且联合图的参考图不含视频帧。
- 一个单元的第二镜及之后的景别不由起始帧约束，依旧由导演说明与提示词决定。
- 格子映射在看板里，改单元正文或导演说明不会自动更新看板；规划依据指纹变化时看板标为过期，由用户决定是否重新规划。
